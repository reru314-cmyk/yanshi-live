晏時｜Y / LIVE v11 — Google Sheet LIVE Feed

覆蓋 GitHub：
- index.html
- sw.js

新功能：
- 「更多」新增 LIVE Google Sheet 發布網址
- 支援 Google Sheets 發布到網路的 CSV
- 開 App 時讀取一次，之後每 30 秒刷新
- 若沒設定 Sheet URL，仍會回退讀 GitHub live-state.json

設定一次即可：
1. 打開《晏時｜LIVE 手機同步》
2. 檔案 → 共用 → 發布到網路
3. 選 LIVE 工作表、格式選 CSV
4. 發布並複製網址
5. App → 更多 → LIVE Google Sheet 發布網址 → 貼上
6. 按「儲存 LIVE Feed」或「立即測試同步」

之後 ChatGPT 更新該 Sheet，手機會自動讀取。
